# Cascade — brand placeholder

Placeholder spec so Phase 2 has concrete values. Replace freely; every consumer is listed so a change is one grep away.

## Palette

| Token | Hex | RGB | Used by |
|---|---|---|---|
| `hx_ink` | `#0B0F14` | 11 15 20 | menu/console background, HUD backdrops |
| `hx_paper` | `#E8EEF2` | 232 238 242 | primary text |
| `hx_accent` | `#38B6FF` | 56 182 255 | selected menu item, HUD highlights, health full |
| `hx_warn` | `#FF8A3D` | 255 138 61 | low health/ammo, warnings |
| `hx_muted` | `#6B7A88` | 107 122 136 | disabled items, secondary text |

## Fonts

| Role | Family | Fallback | Notes |
|---|---|---|---|
| Title / logo text | `DejaVu Sans` bold | `Liberation Sans` | Replaces the HL2 symbol font (`HalfLife2`) so `title "CASCADE"` renders as letters |
| UI / HUD | `Trebuchet MS` (engine default) | `DejaVu Sans` | Unchanged from HL2 `ClientScheme.res` |

No custom `.ttf` is shipped yet. When one is chosen, add it under `game/cascade/resource/` and reference it in `ClientScheme.res` `CustomFontFiles`.

## Logo

| Asset | Size | Path |
|---|---|---|
| Console / main-menu background | 1024×1024 (4:3) and 1024×1024 with 16:9 content (`_widescreen`) | `game/cascade/materials/console/background01[_widescreen].vtf` |

Placeholders are generated by `tools/gen_brand_assets.py` (Pillow). Real art replaces the outputs in place.
